## 1. Исходные данные

Отправная точка — вакансия на Upwork:

> **Web Developer for Home Staging Website**
> Нужен разработчик для сайта бизнеса по home staging (предпродажная подготовка жилья).
> Сайт: чистый, профессиональный, удобная навигация. Разделы: услуги, портфолио, контакты, о компании.
> Обязательные навыки: Web Development, WordPress. Желательно: Web Design, PHP.
> $15–30/час, до 30 ч/неделю, 1–3 месяца.

**Оценка вакансии:** как источник денег — слабая.

| Сигнал | Значение |
|---|---|
| Откликов | 50+ |
| Приглашений на собеседование | 0 |
| Сколько людей клиент нанял за всё время | 0 |
| Платёжная карта клиента | не подтверждена |
| Аккаунт клиента | создан за 2 дня до просмотра |
| Наши Connects (платные «монетки» для отклика) | 0, а нужно 13 |

**Вывод:** шанс выиграть именно эту вакансию низкий. Но ниша хорошая: home staging — это тысячи мелких компаний (в основном в США), и всем нужен примерно одинаковый сайт. Поэтому делаем не «сайт для этого клиента», а **демо, которое можно показывать многим**.

---

## 2. Цели

1. **Научиться** — пройти весь путь от идеи до работающего сайта в интернете и понимать, что происходит на каждом шаге.
2. **Портфолио** — живой сайт по своему адресу, который не стыдно показать заказчику.
3. **Продать** — либо сам сайт конкретной компании, либо переделать его под другого клиента.

---

## 3. Принятые решения

| Вопрос | Решение | Почему |
|---|---|---|
| Как делаем сайт | «быстрый сайт» (технология Astro) | мгновенно грузится, хостинг бесплатный, легко потом переделать под WordPress |
| Приоритет | спокойно научиться, срока нет | нет давления, можно делать нормально, а не как попало |
| Кто пишет код | пишу я, по ходу объясняю | вы разбираетесь в готовом, а не буксуете на синтаксисе |
| Компания на сайте | выдуманная, придумываю я | см. раздел 4 |

**Что такое «быстрый сайт» простыми словами.** Страницы собираются заранее, один раз, и лежат в интернете готовыми файлами — как распечатанный журнал. Никакой базы данных, ничего не «думает» при открытии. Поэтому открывается мгновенно, хостинг бесплатный, и ломать там нечего. Обратная сторона: чтобы поменять текст, нужен человек, который умеет — то есть вы. Админку, как в WordPress, можно прикрутить позже, если появится клиент, которому это нужно.

### Шаг 7. Доводка ✅ готово

Всё, чего глазом не видно, но за что заказчик и платит.

**Чтобы находили в Google:**
- карта сайта `/sitemap.xml` — 12 адресов, с пометками, какая страница какому языку соответствует. Написана вручную, [15 строк](src/pages/sitemap.xml.ts), без лишних дополнений;
- `robots.txt` — разрешение обходить сайт и указание, где карта;
- канонический адрес на каждой странице: поисковик не считает `/quote` и `/quote?utm_source=...` разными страницами;
- данные о компании в машинном виде (schema.org): название, телефон, часы, районы, услуги. Из этого Google рисует карточку компании вместо простой синей ссылки;
- на странице услуг — разметка «вопрос-ответ»: шесть вопросов могут показаться прямо в результатах поиска.

**Чтобы ссылка красиво выглядела в WhatsApp:**
- картинка 1200×630 — [рисуется скриптом](scripts/make-og-image.ts) `npm run og`, шрифт вшит внутрь, чтобы на любом компьютере выходило одинаково;
- свой значок сайта на вкладке — нарисован кодом, весит меньше килобайта.

**Страница 404** — раньше при опечатке в адресе человек упирался в голое сообщение браузера без шапки и без пути назад. Теперь есть своя страница, сразу на двух языках (когда адрес неправильный, язык посетителя определить неоткуда).

**Доступность.** Проверил все семь страниц: по одному заголовку H1, уровни не перепрыгивают, у всех полей формы есть подписи, у всех кнопок текст, разметка размечена на шапку-содержимое-подвал. Контраст всех цветов пересчитал по норме — **нашлась одна ошибка и исправлена**, см. журнал решений.

**Скорость.** При первом заходе браузер скачивает 4 файла общим весом около 105 КБ. Отдельных файлов со скриптами нет вообще — они уместились внутри страницы. Весь сайт целиком, со всеми 13 страницами, шрифтами и картинкой — 660 КБ.

Вы выбрали «я делаю, вы разбираетесь». Чтобы это не превратилось в «Клод что-то наделал, а я смотрю», добавляем правила:

1. **Перед каждым шагом** — коротко: что делаем, зачем и какие есть варианты. Вы принимаете решение.
2. **После каждого шага** — что получилось и почему сделано так. Без терминов, а если термин нужен — сразу расшифровка.
3. **Ваша обязанность — спрашивать.** «Не понял, что это за файл», «а зачем эта строчка» — нормальные вопросы, задавайте их постоянно. Если вы молчите, я не узнаю, что потерял вас.
4. **Раз в несколько шагов — маленькое задание вам.** Поменять текст, добавить услугу, поправить цвет. Своими руками, я только проверю. Без этого знания не закрепляются.
5. **Записываем решения** в раздел 8, чтобы через месяц не гадать, почему сделали именно так.

*Что это.* Программа, которая собирает сайт из кусочков в готовые страницы. Работает только у вас на компьютере, в интернет её выкладывать не надо. Без неё дальше никак.

*Почему сам не могу.* Проверил: Node.js не установлен, а установка требует пароль администратора, которого у меня нет.

Три способа, любой годится:

**Способ А (советую) — вы одной командой, из официального репозитория Ubuntu:**
```
sudo apt update && sudo apt install nodejs npm
```
Введёте свой пароль. Минус: в Ubuntu 24.04 версия слегка устаревшая, но для нас сойдёт.

**Способ Б — свежая версия, тоже одной командой:**
```
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - && sudo apt install -y nodejs
```
Официальный установщик Node.js. Версия новее.

**Способ В — я ставлю сам, без пароля администратора.** Скачаю официальный архив с nodejs.org (файл `node-v22.x-linux-x64.tar.xz`, около 25 МБ) в вашу домашнюю папку. Систему не трогает, удаляется удалением одной папки. **Нужно ваше разрешение на скачивание** — просто скажите «качай».
