# Tal & Tas — сайт компании по предпродажной подготовке квартир

Демонстрационный сайт для выдуманной алматинской компании, которая готовит
квартиры к продаже. Сделан как учебная работа и как образец для портфолио.

**Компания, проекты, отзывы, цены и статистика на сайте придуманы.**
На самом сайте это написано в подвале каждой страницы.

---

## Что внутри

- **13 страниц** на двух языках: русский (основной) и английский
- **Бегунок «до / после»** — перетаскиваемая шторка на фотографиях
- **Форма заявки** с проверкой заполнения и переходом в WhatsApp
- **Фильтр** в портфолио, работающий без перезагрузки страницы

## Из чего сделан

| | |
|---|---|
| Astro 7 | собирает готовые страницы заранее, чтобы сайт открывался мгновенно |
| Обычный CSS | без надстроек: одна система переменных на весь сайт |
| TypeScript | описывает, из чего состоит содержимое, и не даёт забыть перевод |
| sharp | обрабатывает фотографии и рисует картинку для мессенджеров |

Внешних библиотек для интерфейса нет ни одной. Бегунок, фильтр, меню
и проверка формы написаны вручную — около 90 строк кода вместе.

## Сколько весит

При первом открытии главной браузер скачивает **около 250 КБ**: страницу,
стили, два шрифта и две фотографии первого экрана. Отдельных файлов
со скриптами нет — код уместился внутри страницы.

Для сравнения: типичный сайт на WordPress весит 2–4 МБ.

## Как запустить у себя

Нужен Node.js версии 22.12 или новее.

```bash
npm install     # один раз, поставит всё необходимое
npm run dev     # запустит сайт на http://localhost:4321
```

## Все команды

| Команда | Что делает |
|---|---|
| `npm run dev` | запускает сайт для работы; правки видны сразу |
| `npm run build` | собирает готовый сайт в папку `dist` |
| `npm run preview` | показывает собранный сайт как он будет в интернете |
| `npm run photos` | обрабатывает фотографии из `photos-source` |
| `npm run og` | перерисовывает картинку для мессенджеров |
| `npm run kk-review` | собирает таблицу для вычитки казахского перевода |

## Как устроены файлы

```
src/
  data/          всё содержимое сайта, отдельно от оформления
    site.ts        название, телефоны, цены — общее для всех языков
    ru.ts en.ts    тексты главной и общие подписи
    types.ts       перечень того, что должно быть переведено
    pages/         тексты внутренних страниц
  i18n/          всё, что связано с языками
  components/    повторяющиеся блоки
  layouts/       общая обёртка страниц
  pages/         сами страницы; папка en/ — английские версии
  styles/        цвета, шрифты, отступы — в одном файле

public/          файлы, попадающие на сайт как есть
  fonts/           шрифты, разбитые по алфавитам
  photos/          обработанные фотографии

photos-source/   исходники фотографий до обработки
docs/            рабочие документы проекта
scripts/         вспомогательные программы
```

**Главный принцип:** содержимое, оформление и раскладка лежат врозь.
Поменять цену — правится один файл. Поменять цвет кнопок — другой.
Ни то, ни другое не требует трогать страницы.

Благодаря этому сайт однажды переехал из Денвера в Алматы и получил
третий язык, а вёрстку менять не пришлось вовсе.
